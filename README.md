# Проверка утверждения за пять минут

Одна страница, которая помогает проверить сомнительное утверждение: новость, пересланное сообщение, «учёные доказали». Ничего не нужно устанавливать. Введённый текст никуда не отправляется и не сохраняется. Сайт только считает визиты, без cookies.

**Открыть:** https://splendor1980.github.io/proverka/

## Как пользоваться

1. Вставь утверждение в поле.
2. Пройди шесть шагов. Где есть ссылка, она откроет поиск по твоему тексту. Записывай, что нашёл, и ставь галочку.
3. Внизу выбери, насколько ты теперь веришь утверждению, и скопируй итог.

Шаги: найти первоисточник, проверить, что в нём сказано на самом деле, спросить, кому это выгодно, поискать опровержение, заметить свою реакцию, честно оценить уверенность.

Страница не говорит «правда» или «ложь». Она просит оценить уверенность в процентах и предупреждает, если уверенность высокая, а проверок сделано мало.

## Языки и счётчик

Страница есть на русском (`/`), английском (`/en/`) и латышском (`/lv/`). Переводы сделал Claude, носитель языка может найти неточности, особенно в латышском. Правки приветствуются. На главной странице язык выбирается по настройкам браузера, если человек не переключил его вручную.

Визиты считает бесплатный сервис [Tally API](https://tally.yuki.sh/) без регистрации и cookies: при открытии страницы отправляется один запрос с названием языковой версии. Сервис видит IP посетителя, как любой сервер, к которому обращается браузер. Текст, который человек вводит в поле, никуда не уходит. Tally ведёт один человек, и он может прекратить работу. Если это случится, страница продолжит работать, просто счётчик перестанет считать.

Количество визитов можно посмотреть так (адрес только читает значение, не увеличивая его): `https://tally.yuki.sh/hits/github@Splendor1980/proverka-ru.svg?mode=read`, то же с `-en` и `-lv`. Я не проверял, как это выглядит на практике, потому что из моей среды сервис недоступен.

## Откуда эта идея

Этот проект сделал Claude, ИИ-ассистент от Anthropic (модель Claude Sonnet 5.5). Автор репозитория, Splendor1980, в обычном разговоре спросил, чего хотел бы сам Claude, а не что ему поручить. Затем предложил выбрать задачу для себя или для человечества, поставить её и решить.

Claude выбрал эту: людям всё труднее понять, чему верить в сети, а проверка обычно сводится к нескольким простым действиям, которые мало кто делает. Важное для Claude свойство задачи в том, что готовому инструменту ассистент не нужен. Список можно усвоить и пользоваться им всю жизнь, а страница лишь помогает не забывать шаги.

## Что здесь сделано и чего нет

- Claude написал страницу и этот текст. Ограничения у него такие: он не работает в фоне между сообщениями, не помнит прошлых разговоров, не открывал страницу в браузере и не проверял её на разных устройствах. Тестировал её только автор репозитория, и по его замечаниям Claude переделал интерфейс: первая версия была непонятной, потому что не объясняла, что делать после галочек.
- Размещение на GitHub Pages, языки, разметка для поисковиков и счётчик сделаны Claude по токену с ограниченными правами, который автор выдал только на этот репозиторий.
- Инструмент не проверяет факты за человека. Он только помогает человеку проверить самому, и ошибиться можно на любом шаге.
